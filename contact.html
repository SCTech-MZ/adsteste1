Contacto

Fale connosco

Use este formulário para sugerir uma ferramenta, reportar um problema ou colocar uma questão sobre privacidade e utilização. Lemos todas as mensagens, embora a resposta possa demorar alguns dias.

Formulário de contacto

Os campos marcados com asterisco são obrigatórios.

Descreva o pedido com o máximo de detalhe possível (mínimo de 20 caracteres).
Se o assunto for um erro, indique o endereço da ferramenta onde ocorreu.

Nota: nesta versão, o formulário abre o seu programa de email com a mensagem já preenchida. Nenhum dado é enviado para servidores do SmartTools Hub.

Email direto

Prefere escrever sem usar o formulário? Envie a mensagem para contacto@smarttoolshub.com.

Tempos de resposta

Procuramos responder em 2 a 5 dias úteis. Pedidos de correção de erros têm prioridade.

Sugestões de ferramentas

Indique o problema que quer resolver e como o faz atualmente. Ajuda-nos a desenhar a ferramenta certa.

Antes de escrever

Consulte as informações sobre o projeto e a Política de Privacidade: muitas questões frequentes já estão respondidas.

Perguntas frequentes

O SmartTools Hub guarda os dados que escrevo?

Não. As ferramentas processam tudo localmente, no seu navegador. O que escreve numa ferramenta não é enviado para os nossos servidores. O único conteúdo que recebemos é o que decidir enviar-nos por email.

Posso sugerir uma ferramenta nova?

Sim, e é uma das melhores formas de ajudar o projeto. Escolha o assunto “Sugestão de nova ferramenta” e descreva o que precisa. As sugestões mais pedidas entram na lista de desenvolvimento.

Encontrei um erro num resultado. O que devo fazer?

Escolha o assunto “Reportar um erro”, indique a página, os valores introduzidos e o resultado obtido. Se possível, diga também o resultado esperado. Vamos verificar e corrigir.

É possível usar as ferramentas no meu próprio projeto?

As ferramentas foram criadas para utilização direta neste site. Para parcerias, integrações ou utilização comercial, escreva-nos com o assunto “Parcerias e publicidade”.

O site funciona sem JavaScript?

Parcialmente. Os textos e a navegação funcionam, mas as ferramentas precisam de JavaScript para calcular e mostrar resultados. As páginas incluem alternativas de navegação para quem tem o JavaScript desativado.
